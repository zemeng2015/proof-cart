# Community conduct

Treat contributors and users with respect. Discuss code and product choices with
specific evidence; welcome questions and different experience levels.

Harassment, threats, discriminatory abuse, sexual harassment, impersonation,
publishing another person's private information, and deliberate disruption are
not acceptable in project spaces.

Maintainers may edit or remove inappropriate contributions and restrict
participation proportionately. Explain moderation decisions when doing so does
not disclose private information or expose someone to further harm.

For ordinary moderation concerns, open an issue that contains no personal or
sensitive details. If a private report is necessary, request a private contact
route first without publishing the incident details. Security vulnerabilities
follow [SECURITY.md](SECURITY.md). No response-time guarantee is made.
